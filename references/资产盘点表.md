# 资产盘点表 · 我现在有多少家底

> 给完全没盘点过的人:把"我有什么、我欠什么"一项项列清楚,最后自动得到**净资产**——这是所有理财规划的起点。
> 不用精确到个位,估个大概就行;不确定就写"待查"。填完发回,我帮你算净资产 + 分类占比 + 流动性体检。

## 第三步:自动算出

- **总资产** = A + B + C（D 不计入）
- **总负债** = 上表合计
- **净资产 = 总资产 − 总负债** ← 这就是你的家底
- **可动用流动资产** = A + B 中随时能取的部分(剔除锁定项)
- 分类占比(现金 / 投资 / 锁定 / 房产)+ 单一标的集中度体检
