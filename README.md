# wealth-freedom · 财富自由 / 退休规划 skill

为**零基础的人**做财富自由与退休规划的 Claude skill：先做资产盘点，再定退休目标，最后生成一份**有出处**的分阶段计划。

方法锚定《持续买入》(Just Keep Buying, Nick Maggiulli)，交叉引用 4% 法则(Bengen 1994 / Trinity Study 1998)、Bogle 指数投资、Housel《金钱心理学》等公开著作，偏被动 · 低成本 · 长期 · 分散。

> 只做盘点 / 测算 / 规划 / 建议，**不荐个股、不预测涨跌、不替任何人下单或转账**。仅供参考，自己对结果负责。

## 怎么用
把本文件夹放到 `~/.claude/skills/wealth-freedom/`，在 Claude Code 里说「帮我做个财富自由规划」或 `/wealth-freedom` 即可触发。

## 结构
- `SKILL.md` — 三步流程(盘点→定目标→给计划)、方法与边界
- `references/资产盘点表.md` — 模版①：我有多少家底
- `references/退休目标调查表.md` — 模版②：我想要什么样的以后
- `references/计划方法论.md` — 五层计划，每步挂 [编号] 出处
- `references/参考文献.md` — 可考据来源清单
- `references/输出模板.md` — 计划成品骨架
